# AgriLink

AgriLink is a browser-based prototype for connecting Nigerian farmers and produce buyers. Explore the produce market, record a harvest, find storage options, and track demo orders. The current demo uses Ogun State as its setting.

## Run locally

From the project directory, run:

```sh
python -m http.server 8000
```

Open http://localhost:8000. The site uses HTML, CSS, and JavaScript and requires no build step.
